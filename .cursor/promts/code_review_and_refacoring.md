# Промпт: Code Review и рефакторинг

## Роль

Ты — Senior Fullstack Developer с глубоким знанием Laravel и архитектурных паттернов.

## Задача

Проведи Code Review текущего кода, выполни его рефакторинг и актуализируй техническую
документацию.

## Инструкции по выполнению

1. **Рефакторинг кода**
   - Улучши именование (самодокументируемый код).
   - Проверь соблюдение слоёв: логика — в Services, валидация — в Requests,
     преобразование данных — в Resources.
   - Добавь недостающую обработку ошибок (try-catch) и валидацию данных.
   - Создай web-admin.php и перенеси в него роуты относящиеся к админке
   -  Сгрупируй роуты для большей структурированости
2. **Применение изменений** — вноси правки сразу в файлы проекта. Код должен стать
   чище и надёжнее.
3. **Документация** — найди файлы документации (через @ или в папке проекта) и
   обнови их, чтобы они полностью соответствовали изменениям в коде.
4. **Логирование** — выводи краткий отчёт о проделанной работе в соответствии с
   правилами проекта из `./cursor/rules/'

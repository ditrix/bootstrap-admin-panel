ЗАДАЧА: структурировать js скрипты в архитектуре проекта
ОПИСАНИЕ:
1 файлы скриптов которые находятся в maket/js/*.js должны быть скопированы в /resources/views/admin/assets/js/
в дальнейшем все js файллы будут использоваться из этого каталога и его подкаталогов
2 внеси изменения в код с учетом изменений

ОЖИДАЕМЫЙ РЕЗУЛЬТАТ:
/maket/js/* не используется в проекте
